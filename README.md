# Panzer 3D

Downloads und automatische Updates für **Panzer 3D** – Panzergefechte 15 gegen 15 mit 41 Panzern, allein oder im Zug mit bis zu vier Spielern. Früher hieß das Spiel **Panzer Arena 2**; Installation und Spielstand bleiben mit dem neuen Namen erhalten.

## Installieren (nur einmal nötig)

1. Rechts unter **Releases** die neueste Version öffnen und den Launcher herunterladen (die Datei, die auf `-Launcher.exe` endet; in Version 0.1.105 heißt sie noch `PanzerArena2-Launcher.exe`).
2. Den Launcher in einen eigenen Ordner legen, z. B. `Dokumente\Spiele\Panzer 3D`, und starten. Beim ersten Start warnt Windows eventuell
   („Der Computer wurde durch Windows geschützt“): **Weitere Informationen → Trotzdem ausführen**.
3. Der Launcher lädt das Spiel (rund 2 GB) herunter, prüft jede Datei und startet es danach mit **Spielen**.

Die übrigen Dateien im Release mit langen Namen aus Zahlen und Buchstaben sind die Spieldateien; der Launcher lädt sie selbst.

## Updates

Der Launcher sucht beim Start nach neuen Versionen und installiert sie auf Wunsch. Die vorherige Version bleibt erhalten und lässt sich im Launcher wieder wählen.

## Vom bisherigen Launcher wechseln

Wer schon mit dem bisherigen Launcher spielt, lädt den neuen Launcher einmal hier herunter und startet ihn. Er findet die vorhandene Installation, bietet das Update an und behält die bisherige Version als Rückweg. Der Spielstand der Unity-Fassung (ab 0.1.105) bleibt erhalten. Die frühere Godot-Fassung (bis 0.8.15) startet der Launcher ab 0.6.0 nicht mehr, und ihr Spielstand wird nicht mehr übernommen.

## Zusammen spielen

In der Garage **ZUG** öffnen, einen Zug erstellen und den Code weitergeben; bis zu vier Spieler treten mit dem Code bei, die übrigen Plätze füllt die KI.
